Selamat datang di Motion Easy

Motion Easy adalah studio motion graphics yang berjalan langsung di browser. Anda dapat membuat intro, judul, lower third, logo reveal, infografik, background, dan efek partikel tanpa menginstal software editing yang berat.

Tujuan panduan ini: membantu pengguna baru mencapai hasil pertama—satu video MP4 yang berhasil dipreview dan diunduh.

Yang perlu disiapkan

  • Komputer atau laptop.
  • Chrome atau Edge desktop terbaru.
  • Koneksi internet saat membuka aplikasi dan layanan AI.
  • Ruang penyimpanan untuk file video.

Alur kerja Motion Easy

1 · Brief

Jelaskan ide, teks, gaya, warna, durasi, dan tujuan video.

2 · Prompt

Salin prompt otomatis ke AI pilihan Anda.

3 · JSON

Tempel jawaban AI ke area input MotionDefinition.

4 · Hasil

Validasi, preview, lalu ekspor ke MP4.

Privasi

Animasi dan render diproses di perangkat Anda. Data karya tidak perlu diunggah ke server Motion Easy.

Panduan Pengguna Motion Easy03
Alur AI

Menulis brief dan memakai AI

Brief yang baik menjawab enam pertanyaan

  1. Video apa yang ingin dibuat?
  2. Teks apa yang harus muncul?
  3. Siapa penontonnya?
  4. Gaya visual apa yang dipakai?
  5. Warna apa yang digunakan?
  6. Berapa durasi dan rasio videonya?

Contoh brief

Buat video pembuka untuk channel YouTube bernama “Ruang Kreatif”. Tampilkan judul “Ruang Kreatif” dan subjudul “Ide sederhana, dampak luar biasa”. Gunakan gaya neon gelap, aksen cyan, durasi 8 detik. Judul masuk dari bawah dan keluar dengan fade out halus.

Langkah BYO-AI

  1. Isi brief atau pilih tema.
  2. Klik Salin Prompt.
  3. Buka ChatGPT, Claude, Gemini, atau AI pilihan Anda.
  4. Tempel prompt dan kirim.
  5. Salin seluruh JSON hasil AI.
  6. Tempel ke area tempel (sample).
  7. Klik Validasi & Preview.
Jika tidak valid: minta AI mengembalikan hanya satu JSON MotionDefinition valid tanpa sapaan atau penjelasan tambahan. Gunakan juga tombol Salin Prompt Perbaikan setelah validator menampilkan error.

Teknis, tetapi sederhana

Memahami MotionDefinition

MotionDefinition adalah format JSON yang menjelaskan ukuran kanvas, durasi, layer, teks, warna, dan gerakan animasi.

Gambar 3. Kamus Animasi menampilkan contoh JSON yang valid.

Aturan utama

  • version harus bernilai 1.
  • Koordinat dan ukuran memakai fraksi 0 sampai 1.
  • Waktu ditulis dalam detik.
  • Warna memakai hex enam digit, misalnya #4cd7f6.
  • Jenis layer: rect, ellipse, triangle, text, line, atau canvas.
  • Maksimal 60 layer menurut validator aplikasi.
  • Durasi yang didukung: 1 sampai 60 detik.
  • Partikel dan efek canvas harus deterministik agar preview dan ekspor konsisten.
{
  "version": 1,
  "name": "Judul Reveal",
  "canvas": { "w": 1920, "h": 1080, "fps": 30, "durationSec": 6 },
  "layers": []
}

Preview dan output

Validasi, preview, dan ekspor

Preview adalah pemeriksaan sebelum file final dibuat. Putar animasi dari awal sampai akhir dan pastikan semua elemen berada di dalam frame.

Gambar 4. Pilihan paket dan batas ekspor.

Pilih resolusi

ResolusiCocok untukKetersediaan
720pUji cepat dan file kecilGratis
1080pTikTok, Reels, YouTube, presentasiGratis
2KOutput lebih tajamBulanan/Lifetime
4KMaster kualitas tinggiLifetime

Prosedur ekspor

  1. Pastikan preview sudah benar.
  2. Pilih preset resolusi.
  3. Klik Ekspor MP4.
  4. Jangan menutup tab saat proses berjalan.
  5. Tunggu pesan selesai.
  6. Periksa folder Downloads/Unduhan.
Kuota Gratis: 5 ekspor MP4 per hari. Hanya ekspor yang berhasil yang mengurangi kuota. Paket Premium mendapat ekspor tanpa batas.

Fitur premium

Bulk ZIP dan Enlarge-MB

Bulk ZIP

Render banyak karya sekaligus dan unduh sebagai satu file ZIP. Cocok untuk variasi judul, seri media sosial, banyak produk, atau beberapa versi bahasa.

Tersedia: Bulanan dan Lifetime.

Enlarge-MB

Pilih ukuran 10, 25, atau 50 MB untuk memenuhi syarat ukuran minimum platform atau agensi.

Tersedia: Bulanan dan Lifetime.

Workflow untuk konten vertikal

  1. Pilih atau tulis brief untuk TikTok/Reels.
  2. Gunakan hook besar pada 1–2 detik pertama.
  3. Batasi teks agar mudah dibaca.
  4. Sisakan safe area dari tepi layar.
  5. Ekspor 1080p untuk penggunaan umum.

Workflow microstock

Gunakan desain bersih dan mudah dipakai ulang. Periksa hak penggunaan font, aset, musik, dan merek pihak ketiga sebelum menjual atau menerbitkan hasil.

Troubleshooting cepat

MasalahYang harus dilakukan
JSON tidak validHapus teks di luar JSON, periksa koma dan kutip, lalu gunakan prompt perbaikan.
Preview glitchKurangi layer/partikel, kurangi efek canvas, muat ulang, dan tutup aplikasi berat.
Teks terpotongPendekkan teks, kecilkan font, atau pindahkan elemen menjauh dari tepi.
Export gagalGunakan Chrome/Edge desktop, coba 720p/1080p, kurangi layer, lalu ulangi.
Export lambatSambungkan charger, tutup aplikasi lain, turunkan resolusi, dan kurangi partikel.
File tidak ditemukanPeriksa Downloads, daftar download browser, izin download, dan ekstensi .mp4.
Premium terkunciPeriksa aktivasi lisensi, muat ulang Studio, dan pastikan kode sesuai paket.
Kuota habisTunggu reset harian atau upgrade ke Premium.

Informasi saat menghubungi admin

  • Screenshot masalah.
  • Pesan error lengkap.
  • Browser dan sistem operasi.
  • Resolusi yang dipilih.
  • Paket yang digunakan.
  • Langkah terakhir sebelum masalah.
Keamanan: jangan mengirim kode lisensi ke grup atau ruang publik. Gunakan kanal admin resmi.
